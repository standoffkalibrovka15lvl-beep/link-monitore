# Link Monitor (с согласия посетителя)

## Что делает
- Показывает страницу с уведомлением о сборе аналитики.
- Отправляет Telegram-уведомление только после явного согласия посетителя.
- Сохраняет время, User-Agent и маскированный IP.
- Показывает последние записи через защищённый `/stats?key=ВАШ_STAS_KEY`.

Геолокация по IP не подключена: она приблизительна и требует отдельного прозрачного уведомления и выбора геосервиса.

## Переменные окружения Render
- `BOT_TOKEN` — токен Telegram-бота (секрет Render, никому не публиковать).
- `CHAT_ID` — уже указан числовой Telegram ID владельца.
- `STATS_KEY` — придумайте длинный случайный пароль для просмотра статистики.
- `DATABASE_PATH` — необязательно; для постоянного хранения на Render нужен подключённый persistent disk и путь на нём.

## Развёртывание
Создайте публичный Git-репозиторий, загрузите все файлы и вставьте URL репозитория в Render → New Web Service → Public Git Repository.
Задайте переменные окружения и нажмите Deploy.

Важно: бесплатный ephemeral filesystem Render может сбрасываться при перезапуске. Для долговременной истории подключите постоянный диск или внешнюю БД.
